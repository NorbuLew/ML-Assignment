## Cross-cutting requirements, easy to miss

- Dataset links are the **first** item in the reference list. This project uses a
  simulated environment and no external dataset -- say so explicitly rather than
  omitting the item.
- The **Streamlit dashboard link and video link** go on **slide 2** of the deck
  and as the **last item** of the report's table of contents.
- References in **APA** with **DOIs**.
- Report must be in **Google Docs** to generate the originality report.
- Rubric goes in **separately**, not attached to the report.
- Video: assignment title only, no member names.
- Presentation: formal attire, all members present per the group contract.

## What item 1 must contain (spec wording)

Each sub-section of the coding file needs:
- purpose of the sub-section and the technique being tested
- setup: libraries/packages and tools used
- parameter settings and configurations used
- commented code segments, clearly separated
- results and observations
- patterns or insights observed
- key findings and their implications

Plus deployment: the Streamlit dashboard, for interactive visualisation.
